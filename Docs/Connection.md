# Схема підключення (орієнтовна)

## SPI для цифрових потенціометрів
| STM32 | MCP4251 |
|---|---|
| PA5 (SPI1_SCK) | SCK |
| PA6 (SPI1_MISO) | SO |
| PA7 (SPI1_MOSI) | SI |
| PA4 (SPI1_NSS1) | CS P-pot |
| PB0 (GPIO_OUT) | CS D-pot (або окремий NSS) |

## Зворотній зв'язок/вимірювання
| STM32 | Призначення |
|---|---|
| PA0 (ADC1_IN0) | Вимірювання похибки/виходу об'єкта |
| PA1 (ADC1_IN1) | Додатковий канал для контролю |

## Інтерфейс
| STM32 | Призначення |
|---|---|
| USART2 (PA2/PA3) | Відладка через UART/USB-UART |

## Принцип керування
- Для зміни Kp виставляти опір цифрового потенціометра в підсилювальному ланцюгу PD
- Для зміни Td = R*С виставляти опір цифрового потенціометра в RC ланцюгу диференціатора
