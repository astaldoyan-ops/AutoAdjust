# AutoAdjustPDRegulator

Проєкт для автоматичного налаштування параметрів P та D аналогового PD-регулятора за допомогою STM32.

## Мета
З'єднати борт STM32 з аналоговим PD-регулятором таким чином, щоб мікроконтролер міг самостійти зміювати параметри P і D.

## Концепція
Параметри P (пропорційний) та D (диференціальний) аналогового PD-регулятора змінюються шляхом керування цифровими потенціометрами (наприклад, MCP4251) через SPI STM32.

## Компонентний склад (рекомендований)
- STM32F446RE (Nucleo-F446RE) або STM32F103C8T6 (BluePill)
- MCP4251 - подвійний цифровий потенціометр 10кОм по SPI
- TL074 / LM324 / OPA2376 - ОП для побудови PD-контуру

## Функціонал STM32
- SPI1 для керування цифровими потенціометрами (P, D)
- ADC1 для вимірювання виходу/похибки регулятора
- TIM (PWM або захоплення) для завдання збурення/референсу
- UART/USB для логування та діалогу
- GPIO для керування CS цифрових потенціометрів
